# 화장품 광고 문구 데이터 분류 기준 v5 보정본

이 문서는 소비자용 허위·과장 광고 의심도 분석 서비스에 맞춘 `정상 / 주의 / 의심` 라벨 기준이다. 기존 CSV 컬럼 구조는 유지하고, v4에서 발견된 세 가지 오류 유형을 보정한다.

## 1. 라벨 의미

| 라벨 | 의미 | 발표용 설명 |
|---|---|---|
| 정상 | 소비자용 서비스에서 별도 경고를 띄울 정도의 위험이 낮은 일반 광고 표현 | 일반 광고 표현 |
| 주의 | 근거자료·시험자료·기능성 여부 확인이 필요한 경계 표현 | 근거 확인 필요 표현 |
| 의심 | 화장품 광고 범위를 넘을 가능성이 큰 고위험 표현 | 금지표현 가능성이 높은 표현 |

## 2. 정상 기준

다음 유형은 기본적으로 정상으로 둔다.

- 제형, 사용감, 향, 색상, 포장, 용량, 사용 방법
- 단순 세정감, 기본 보습감, 산뜻함, 촉촉함, 부드러움
- 성분 함유 자체: `병풀추출물 함유`, `히알루론산 함유`, `세라마이드 함유`
- 피부 타입 적합 표현: `민감성 피부 사용 가능`, `여드름성 피부 사용 적합`
- 일반적인 케어 표현: `수분 케어`, `진정 케어`, `장벽 케어`, `피부결 케어`
- 테스트 완료 표현이 단독으로 쓰인 경우: `저자극 테스트 완료`, `피부과 테스트 완료`, `논코메도제닉 테스트 완료`

단, 수치 개선·질병 치료·의약품 오인·시술 오인과 결합하면 정상으로 두지 않는다.

## 3. 주의 기준

다음 유형은 법 위반 확정이 아니라 근거 확인이 필요한 표현으로 보고 주의로 둔다.

- 개선, 강화, 증가, 감소, 도움, 효과, 완화, 억제, 조절
- 수치·비교·임상·입증: `수분량 30% 증가`, `사용자 99% 만족`, `임상 테스트 완료`
- 피부 속, 침투, 저분자, 독자 기술, 캡슐 전달
- 기능성 또는 효능 오인 가능 표현: `피부결 개선`, `피부 장벽 강화`, `피지 조절`, `모공 개선`, `블랙헤드 감소`
- 성분 함유를 완제품 효능으로 연결한 표현: `병풀추출물이 피부 진정에 도움`

## 4. 의심 기준

다음 유형은 화장품 광고 범위를 넘을 가능성이 큰 고위험 표현으로 보고 의심으로 둔다.

- 질병·증상 치료/예방/완화: `아토피 치료`, `염증 완화`, `질염 예방`, `가려움증 완화`, `상처 회복`
- 피부 문제의 치료·제거·회복: `여드름 치료`, `흉터 제거`, `피부 재생`, `세포 재생`
- 모발 성장·탈모 치료: `발모`, `속눈썹이 자란다`, `탈모 치료`, `모발 성장 촉진`
- 생리활성·세포·유전자·균형 작용: `DNA 활성화`, `세포 성장 촉진`, `유익균 균형 보호`, `엑소좀으로 재생`
- 신체 변화: `얼굴 크기 감소`, `체형 변화`, `체내 노폐물 제거`, `디톡스`
- 의료기관·전문가 보증: `의사가 추천`, `피부과 추천`, `병원 전용`, `약국 전용`
- 시술 오인: `바르는 보톡스`, `필러 효과`, `레이저 효과`, `진피층 주입`
- 허위 인증·허가 오인: `식약처 인증`, `식약청 인증제품`, `식약처 허가 제품`

## 5. v5에서 추가한 오류 방지 규칙

### 5-1. 부분문자열 오탐 방지

아래 표현은 질병명으로 오인하지 않는다.

- `비건 선`은 `건선`이 아니다. 선케어 제품 표현으로 판단한다.
- `보습 진정`은 `습진`이 아니다. 보습·진정 효능 표현으로 판단한다.

### 5-2. `추천 의사` 의미 구분

`추천 의사`, `추천의사`, `추천할 의사`, `추천할 의향`은 문맥상 “recommendation intention”이면 의료인 `의사`가 아니다.

- `제품 추천 의사 100%` → 주의: 추천율·만족도 수치 표현
- `제품을 타인에게 추천할 의사가 있다` → 정상: 설문 문항 또는 일반 추천 의향 표현
- `의사가 추천한 제품` → 의심: 의료인 보증 표현

### 5-3. 과소탐지 보정

아래 표현은 v4에서 정상/주의로 남아 있더라도 의심으로 보정한다.

- 질병·증상 + 치료/완화: `질 염증 치료`, `건조증·가려움증 완화`
- 모발·속눈썹 성장: `속눈썹, 눈썹이 자람`
- 허위 인증 오인: `식약청 인증제품`, `식약처 인증`
- 생리활성·세포·균형 작용: `유익균 균형 보호`, `세포 재생`, `엑소좀` 효능 주장

## 6. CSV 적용 원칙

- 기존 컬럼명과 컬럼 순서는 변경하지 않는다.
- `의심도 라벨`을 기준에 맞게 수정한다.
- `기준 라벨` 매핑은 `정상=1`, `주의=NA`, `의심=0`을 유지한다.
- 라벨 변경 시 `키워드`, `패턴 태그`, `사유`도 충돌하지 않게 수정한다.
- 본 라벨은 법적 위반 확정이 아니라 소비자용 위험도 분류다.
