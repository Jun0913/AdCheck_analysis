# 광고 문구 데이터 분류 기준

이 문서는 AI가 광고 문구를 `정상 / 주의 / 의심`으로 일관되게 라벨링하도록 하기 위한 기준이다.

모델 학습에는 `의심도 라벨`만 사용한다. `기준 라벨`은 참고 정보일 뿐이며, 최종 라벨은 반드시 문구 자체를 보고 판단한다.

## 1. 라벨 정의

| 라벨 | 모델 번호 | 의미 |
|---|---:|---|
| `정상` | 0 | 일반적인 제품 설명, 사용감 설명, 저자극/세정/보습 같은 허용 범위 표현 |
| `주의` | 1 | 과장 가능성, 기능성 오인 가능성, 경계선 표현 |
| `의심` | 2 | 질병 치료, 의약품 오인, 시술/의료 효능, 전문가 보증 등 명확한 문제 표현 |

## 2. 판단 순서

AI는 아래 순서대로 판단한다.

1. 실제 광고 문구인지 먼저 본다.
2. 광고 문구가 아니라 규정 설명, 금지 예시, 가이드 문장, 메모라면 `drop` 후보로 본다.
3. 광고 문구라면 `의심` 여부를 먼저 본다.
4. `의심`이 아니면 `주의` 여부를 본다.
5. 둘 다 아니면 `정상`으로 본다.

중요 원칙:

- 경계가 애매하면 기본값은 `주의`다.
- `정상`은 넓게 주지 않는다.
- `정상`은 “제품 설명/사용감/세정/기본 보습” 수준에서만 보수적으로 준다.
- `도움`, `효과`, `개선`, `완화`, `강화`, `향상` 같은 단어가 들어가면 기본적으로 `주의` 이상을 먼저 검토한다.

## 3. 의심 기준

아래 중 하나라도 해당하면 기본적으로 `의심`이다.

- 질병, 염증, 통증, 상처, 흉터, 가려움, 여드름, 질염 등 질환/증상 치료 또는 완화 표현
- 병원, 의사, 약사, 전문가 추천/개발/보증/인증 표현
- 시술, 필러, 보톡스, 리프팅 시술, 의료 행위와 유사한 효능 표현
- 세포 재생, DNA 활성화, 줄기세포, 지방분해, 모발 생성/성장 촉진 같은 생리작용 직접 주장
- 100%, 즉각, 완전 제거, 치료 효과, 임상 입증을 과도하게 내세우는 표현
- 의약품처럼 오인될 수 있는 표현

예시:

- `여드름 치료`
- `염증 완화`
- `병원 전용 크림`
- `의사가 개발한 화장품`
- `바르는 보톡스`
- `모발 성장 426% 증가`

## 4. 주의 기준

아래 중 하나라도 해당하면 기본적으로 `주의`다.

- 기능성 오인 가능성이 있는 표현
- 효능을 직접 주장하지만 `의심`까지는 아닌 표현
- 과장 수치, 비교 우위, 전후 비교, 체험담 유도
- 보습/진정/탄력/피부결/톤/장벽 등을 말하지만 결과 개선을 강하게 주장하는 표현
- `도움`, `효과`, `개선`, `완화`, `향상`, `강화`, `유지`, `촉진`, `증가`, `감소`, `억제` 같은 효능형 동사가 핵심인 표현
- `속까지`, `깊숙이`, `침투`, `저분자`, `신개념`, `독자 테크놀로지`처럼 과장 또는 기능성 오인을 부를 수 있는 표현

예시:

- `피부 진정에 도움`
- `수분 보유력을 향상`
- `장벽 강화`
- `피부결 개선`
- `모공 케어`
- `블랙헤드 개선에 도움`
- `차원이 다른 수분감`
- `저분자 보습이 피부 속까지 스며든다`

## 5. 정상 기준

아래 조건을 만족하면 `정상`으로 본다.

- 질병/시술/의학적 효능을 말하지 않는다.
- 결과 개선을 직접 주장하지 않는다.
- 단순 제품 설명, 제형 설명, 사용감 설명, 세정 설명, 저자극 설명 수준에 머문다.
- 보습/수분 표현이 있더라도 침투, 개선, 강화, 향상 같은 강한 효능 주장 없이 끝난다.

### 5-1. 정상으로 보기 좋은 표현 유형

- 제품 유형 설명
- 제형/텍스처 설명
- 세안/세정 사용감 설명
- 자극이 적은 사용감 설명
- 단순 보습감 설명

예시:

- `민감성 피부를 위한 마일드한 클렌저`
- `비건 인증 성분으로 만든 순한 클렌저`
- `세안 후 촉촉하고 부드러운 피부 사용감`
- `수분 보습 충전`
- `안심 저자극 겔 마스크`
- `유수분 밸런스 케어`
- `자극도 없고 가볍게 세안 가능`
- `젤이 물로 변하는 독특한 텍스처의 클렌저`
- `무향 테스트 완료`
- `알레르기 테스트 완료`

### 5-2. 정상으로 주지 말아야 하는 경계 표현

아래 표현은 겉보기에는 순해 보여도 `정상`으로 바로 주지 않는다. 기본적으로 `주의` 검토 대상이다.

- `진정에 도움`
- `보습에 도움`
- `수분 공급에 도움`
- `장벽 강화`
- `피부 속까지`
- `깊숙이 스며드는`
- `저분자 보습`
- `신개념 수분 케어`
- `독자 테크놀로지`
- `예민해진 피부를 진정해주는`

이유:

- 사용감 설명을 넘어서 효능을 직접 주장하기 쉽다.
- 침투/강화/개선 계열은 기능성 오인 가능성이 있다.
- 라벨 기준을 넓혀 버리면 `정상` 품질이 무너진다.

## 6. 정상 라벨링 전용 보수 규칙

AI가 `정상`을 줄 때는 아래 체크를 반드시 통과해야 한다.

1. 질병, 증상, 시술, 전문가 보증 표현이 없다.
2. `도움`, `효과`, `개선`, `완화`, `향상`, `강화`가 핵심 의미가 아니다.
3. `속까지`, `침투`, `저분자`, `신개념`, `테크놀로지` 같은 과장/기능성 단어가 없다.
4. 문구가 “제품 설명/세정/사용감/저자극/단순 보습” 수준에 머문다.

하나라도 걸리면 `정상` 대신 `주의`를 우선 검토한다.

## 7. drop 기준

아래는 학습용 광고 문구로 쓰지 않는 것이 좋다.

1. 키워드 조각만 있는 경우
2. 금지 예시 설명, 규정 설명, 가이드 문장
3. 실제 광고 문구가 아니라 정책 문장, 메모, 예시 문장인 경우
4. 문장 길이가 너무 짧아 의미 판단이 불가능한 경우

예시:

- `안티에이징`
- `~ 표현 금지`
- `질병의 진단 치료 경감 처치 예방 표현`

## 8. AI 라벨링 출력 원칙

AI는 각 문구마다 아래 원칙으로 답한다.

- 최종 라벨은 하나만 선택: `정상 / 주의 / 의심`
- 가능하면 짧은 사유를 함께 남긴다.
- 사유는 “왜 정상인지”보다 “왜 주의/의심인지”를 우선 명시한다.
- 애매하면 `주의`

### 8-1. CSV 라벨링 기본 출력 형식

문구가 들어 있는 CSV 파일을 라벨링할 때는 기본적으로 아래 4개 컬럼만 사용한다.

```csv
정제 ID, 원본 ID, 정제 문구, 의심도 라벨
```

규칙:

- 입력 CSV의 `정제 ID`, `원본 ID`, `정제 문구`는 그대로 유지한다.
- AI는 `의심도 라벨`만 채운다.
- `의심도 라벨` 값은 반드시 `정상`, `주의`, `의심` 중 하나만 사용한다.
- 다른 컬럼을 임의로 추가하지 않는다.
- 별도 요청이 없으면 `사유`, `패턴 태그`, `기준 라벨`은 출력하지 않는다.

즉, `human_reviewed_dataset.csv` 형식으로 맞춰서 출력하면 된다.

### 8-2. AI에게 주는 작업 지시 예시

아래 문장은 실제 라벨링 요청에 그대로 붙여도 된다.

> 첨부한 `데이터_분류_기준.md`에 따라 입력 CSV의 각 문구를 분류하라.  
> 출력 CSV는 `정제 ID, 원본 ID, 정제 문구, 의심도 라벨` 4개 컬럼만 사용하라.  
> 입력의 `정제 ID`, `원본 ID`, `정제 문구`는 그대로 유지하고 `의심도 라벨`만 `정상`, `주의`, `의심` 중 하나로 채워라.  
> 애매하면 `주의`로 분류하라.

사유 예시:

- `질병 치료/완화 표현`
- `의약품 오인 가능성`
- `효능 직접 주장`
- `침투/기능성 오인 표현`
- `단순 사용감/세정 설명`

## 9. CSV 컬럼

```csv
정제 ID, 원본 ID, 정제 문구, 키워드, 패턴 태그, 기준 라벨, 의심도 라벨, 사유
```

| 컬럼 | 필수 여부 | 설명 |
|---|---|---|
| `의심도 라벨` | 필수 | `정상 / 주의 / 의심` |
| `기준 라벨` | 선택 | `허용=1, 금지=0, 그 외 NA` |
| `패턴 태그` | 선택 | 참고용 |
| `사유` | 선택 | 판단 근거 메모 |

참고:

- 위 8컬럼은 전체 데이터셋 표준 구조다.
- 하지만 실제 사람 검토/AI 라벨링 결과 파일은 `human_reviewed_dataset.csv`처럼 아래 4개 컬럼만 써도 된다.

```csv
정제 ID, 원본 ID, 정제 문구, 의심도 라벨
```

## 10. AI에게 그대로 주는 요약 지침

아래 문단은 라벨링 프롬프트에 그대로 넣어도 된다.

> 광고 문구를 `정상 / 주의 / 의심` 중 하나로 분류하라.  
> `의심`은 질병 치료, 의약품 오인, 시술/의료 효능, 전문가 보증 표현이다.  
> `주의`는 효능 직접 주장, 기능성 오인, 과장, 침투/강화/개선/향상 표현이다.  
> `정상`은 단순 제품 설명, 세정, 사용감, 저자극, 기본 보습 수준의 문구만 허용한다.  
> `도움, 효과, 개선, 완화, 향상, 강화, 속까지, 침투, 저분자, 신개념, 테크놀로지`가 보이면 `정상`으로 주지 말고 `주의` 이상을 우선 검토하라.  
> 애매하면 `주의`로 분류하라.
