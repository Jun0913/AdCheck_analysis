# KoBERT 모델 비교 보고서

작성일: 2026-05-05

## 비교 목적

재학습한 최신 KoBERT 모델과 기존 서비스 기준 KoBERT 모델의 성능 차이를 같은 평가셋 기준으로 비교했다.

## 비교 대상

| 구분 | 경로 | 비고 |
|---|---|---|
| 새 모델 | `models/kobert_ad_classifier` | 재학습 모델 |
| 기존 모델 | `models/kobert_ad_classifier_2026-04-13` | 기존 기준 모델 |

## 평가 방법

- 평가 입력: `data/eval/eval_candidates_curated.csv`
- 평가 건수: 169건
- 비교 기준: 현재 서비스 추론 파이프라인 전체
- 파이프라인: `Rule Engine -> KoBERT`
- 실행 스크립트: `training/eval_eval_set.py`

## 핵심 결론

- KoBERT 단독 성능은 새 모델이 더 좋았다.
- 서비스 파이프라인 전체 성능은 초기에는 기존 모델이 근소 우세였다.
- 원인은 새 모델 자체보다, 당시 규칙 및 점수 보정 기준이 기존 모델 분포에 더 맞춰져 있었기 때문으로 봤다.
- 이후 보정 기준을 조정하자 새 모델이 기존 기준 모델보다 더 나은 최종 성능을 보였다.

## 비교 요약

### 초기 파이프라인 비교

- 새 모델 정확도: `0.8994`
- 기존 모델 정확도: `0.9053`

### 튜닝 후 새 모델

- 튜닝 후 새 모델 정확도: `0.9231`
- 오답 수: `17 -> 13`

## 해석

- 새 모델은 정상/허용 문구를 더 보수적으로 지키는 경향이 있었다.
- 기존 모델은 일부 위험 문구를 더 공격적으로 잡는 경향이 있었다.
- 따라서 단순 모델 교체보다, 현재 규칙 엔진과 KoBERT 점수 해석 기준을 함께 조정하는 게 더 중요했다.

## 후속 반영

- `analysis/services/ai_analyzer.py`
  - KoBERT 점수 해석 기준 조정
- `analysis/services/rule_engine.py`
  - 깊은 층 전달, 강한 효능 시사 표현 보강
- `training/eval.py`
  - 서비스 추론과 동일한 입력 처리 기준 반영

## 현재 판단

이 비교는 과거 시점의 튜닝 로그이며, 현재 서비스 기본 모델은 `kobert_ad_classifier_relabel` 기준으로 운영한다.
